VE Analyzer Information
Workflow

Review VE and target, set qualification and limits, verify readiness and lambda-delay authority, Run Analysis, review proposal/evidence, then accept or export.

Standard table editing

The same toolbar vocabulary is used directly beside each editable table. Interpolation has three explicit directions like MLV: horizontal, vertical, and both directions. Right-click an interpolation tool for Linear/neighbor-informed Shape-preserving or Bilinear/Boundary-surface mode, strength, and clamping. Right-click − or + to change the increment step. Right-click Smooth to set smoothing intensity; 1.0 = 100%. Pin protects selected cells from +/−, Smooth and Interpolate. Horizontal/vertical interpolation treats pinned cells inside the selection as extra anchors, making it possible to preserve trusted analysis results while filling or reshaping the cells between them. Brush behaves like a spray tool: hold the pointer to continuously accumulate the configured adjustment, or drag while held to sweep the weighted brush across the table. Shift reverses the adjustment direction.

Touch and keyboard

EpicScope-style table selection is shared by VE, Target and Lambda Delay: click/tap selects one cell; drag selects a rectangular range; Shift+click or Shift+arrow extends a rectangle from the anchor; Ctrl/Cmd+click toggles individual cells; Ctrl/Cmd+drag adds another rectangular region. Typing a number immediately replaces the selected cells with live preview, Backspace edits from the anchor value, Enter/F2 edits the existing value, Delete reverts/clears according to table semantics, and Esc clears selection.

Target table

When the target table is visible it gets its own standard table-editing toolbar. In split view, VE Proposal tools affect only the VE proposal and Target tools affect only the target table.

Advanced input mapping

Normal workflow uses automatic table-axis and channel-role resolution. Advanced exposes manual VE/Target axis mapping and explicit source-role overrides only for ambiguous or non-standard tune/log definitions.

Analysis exclusions

Exclusions use the same expression vocabulary as Math Channels, but return a sample-level reject decision instead of creating a calculated channel. Any enabled rule that evaluates true/non-zero excludes that sample from VE evidence. Rules can be named, saved, enabled/disabled and reused.

Analysis scope navigator

The thin timeline is temporal orientation for VE analysis, not a Logger graph. It shows the whole recording, the selected analysis region and A/B markers when relevant. After analysis it may add lightweight useful/weak/excluded density. Use Open in Logger for real trace inspection.

Mixture identity

AFR and Lambda are explicit identities. A mismatch between analysis scale, actual-mixture source and target table raises a compact warning rather than silently converting or relabeling the data.

Accepted proposal markers

After Accept Proposal, changed VE cells keep only a small upper-right marker: white for normal accepted proposal changes and black for user-altered weak-evidence cells. Markers survive table/view changes during the current analyzer session, and reset on the next analysis run or page reload.

VE Analyzer Settings
Persistent custom settings

Custom Qualification, Cell Change, proposal view, application strength, table density and floating-window layout are stored locally and restored later.
